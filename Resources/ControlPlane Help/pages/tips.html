Tips and Tricks

This page gives examples of useful ways that ControlPlane can be used, especially via actions.

Shortcuts recipe gallery

On macOS 26 (Tahoe) there is no public Control Center API for third-party apps. ControlPlane does not turn Focus, VPN, Bluetooth power, or Stage Manager on or off itself, and it does not use private automation. Create a Shortcut that uses the public Shortcuts action named below, then attach Run Shortcut (or Set Focus for Focus) and enter that Shortcut’s exact name.

Suggested names are only labels you choose in the Shortcuts app. They are not built into ControlPlane. Use the same spelling in the action parameter, or paste the identifier from shortcuts list --show-identifiers. The first run may ask you to allow the Shortcut.

Focus — Set Focus

Replaces the unsupported Toggle Notification Center Alerts action. In Shortcuts, search for the system action Set Focus (not a private Notification Center preference). Choose a Focus you already have (Do Not Disturb, Work, Sleep, …) and turn it on or off.

Suggested Shortcut name: Enable Work Focus

  1. In the Shortcuts app, add Set Focus, pick the Focus, and turn it on (or off, for a departure Shortcut such as Turn Do Not Disturb Off).
  2. In ControlPlane Preferences, add a Set Focus or Run Shortcut arrival action and enter Enable Work Focus.

Focus evidence only reports whether Focus is on or off. It cannot see the mode name. Use this recipe when a context should turn a named Focus on or off.

VPN — Set VPN

Replaces the unsupported VPN action. In Shortcuts, search for the system action Set VPN. It connects, disconnects, or toggles a VPN configuration already on this Mac. It can also change On Demand; changing On Demand asks for an administrator password. ControlPlane does not change On Demand and does not create VPN configurations.

Suggested Shortcut names: Connect Work VPN on arrival, Disconnect Work VPN on departure.

  1. Confirm the VPN appears in System Settings → VPN. Third-party VPN apps may not show up in Set VPN.
  2. Add Set VPN, choose that configuration, and set the operation to Connect (or Disconnect).
  3. In ControlPlane, add a Run Shortcut action and enter Connect Work VPN.

Bluetooth — Set Bluetooth

Replaces the unsupported Toggle Bluetooth action, which used private Bluetooth power APIs. In Shortcuts, search for the system action Set Bluetooth. It turns the Bluetooth radio on or off. It does not pair or connect a device.

Suggested Shortcut names: Turn Bluetooth On and Turn Bluetooth Off.

  1. Add Set Bluetooth and choose Turn On or Turn Off. Do not use a shell script.
  2. In ControlPlane, add a Run Shortcut action and enter Turn Bluetooth On.

If an administrator blocks Bluetooth power changes, the Shortcut fails and ControlPlane cannot override that. To connect a paired device after the radio is on, use Connect Bluetooth Device (that action does not turn Bluetooth power on).

Stage Manager — Set Stage Manager

ControlPlane has no Stage Manager action. On macOS 26, Shortcuts includes the system action Set Stage Manager, which turns Stage Manager on or off. It does not arrange windows. If that action is missing, Stage Manager is not available on this Mac — do not look for a private WindowServer toggle.

Suggested Shortcut names: Turn Stage Manager On and Turn Stage Manager Off.

  1. Add Set Stage Manager and turn it on or off.
  2. In ControlPlane, add a Run Shortcut action and enter Turn Stage Manager On.

Switch Context from Shortcuts

To force a context from Shortcuts or Spotlight:

  1. Leave ControlPlane running in the menu bar.
  2. Open the Shortcuts app and add the Switch Context action from ControlPlane, then pick the context name shown in the Force Context status menu. Nested contexts that share a name appear as Parent/Child.
  3. Or ask Spotlight for Switch context in ControlPlane.

This uses the same path as choosing a context from the status menu. It does not require App Sandbox, and ControlPlane stays a menu-bar agent. This is separate from the system Set Focus, Set VPN, Set Bluetooth, and Set Stage Manager recipes above: those run your Shortcuts; this lets Shortcuts force a ControlPlane context.
