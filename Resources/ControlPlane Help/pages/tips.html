Tips and Tricks

This page gives examples of useful ways that ControlPlane can be used, especially via actions.

To set Focus when entering a context:

  1. Open the Shortcuts app and create a shortcut that sets the Focus you want (for example Do Not Disturb or Work). Name it something memorable, such as Enable Work Focus.
  2. In ControlPlane, add a Set Focus or Run Shortcut arrival action on the context and enter that exact Shortcut name (or its identifier from shortcuts list --show-identifiers) as the parameter.

The legacy Toggle Notification Center Alerts action is unsupported on modern macOS; do not rely on private Notification Center preferences.

To toggle Bluetooth when entering a context:

  1. Open the Shortcuts app and create a shortcut that sets Bluetooth on or off. Name it something memorable, such as Toggle Bluetooth.
  2. In ControlPlane, add a Run Shortcut arrival action on the context and enter Toggle Bluetooth (or the identifier) as the parameter.

The legacy Toggle Bluetooth action is unsupported on modern macOS; do not rely on private IOBluetooth Preference APIs.
