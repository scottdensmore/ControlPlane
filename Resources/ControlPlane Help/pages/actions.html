Configuring Actions

Actions are triggered when ControlPlane decides to change your context. They can be performed when you arrive at a context, leave a context or both and individual actions can be delayed for a period of time.

Most actions will be Arrival actions; that is, they will be triggered when ControlPlane switches to that context. The alternative is a Departure action, which is triggered when ControlPlane switches away from that action's context. In this case, the delay parameter will be the length of time from the action being triggered until the context is switched.

On macOS 15 (Sequoia), some historical actions are gated or retired and will not appear as supported options. See Unavailable on macOS 15 below.

Default Printer actions

Changes the default printer

Default Browser action

Changes default browser based on a list of installed browsers

Desktop Background action

Changes the desktop background.

Display Brightness action

Unsupported on modern macOS (Tahoe / 15/16). Display brightness cannot be set reliably via public APIs on Apple silicon. Use keyboard brightness keys, Control Center, System Settings → Displays, or a Run Shortcut / ShellScript action instead.

Display Sleep Time action

Change the timeout for when the display will go to sleep

Lock Keychain action

Lock or unlock the key chain

Mount actions

Actions of type Mount attempt to mount a network volume (typically smb://; legacy afp:// URLs may fail on modern macOS where AFP is unavailable).

Mute actions

Actions of type Mute will mute or unmute your system audio.

Network Location actions

Unsupported on macOS 15. Actions of type NetworkLocation are not available on modern macOS. Network Locations were removed from System Settings (Ventura and later), so ControlPlane no longer offers this action.

Open actions

Actions of type Open are the most general actions. Upon triggering, ControlPlane will open that file: if it is an application, it will be launched; if it is an AppleScript, it will be executed; otherwise, it will be opened with that file's default application. This is roughly equivalent to double-clicking on that file in Finder.

Although Open will still run AppleScript files for backwards compatibility, AppleScripts and shell scripts should use the ShellScript action now instead.

Open URL action

Open the given URL

Quit Application action

Enter the name of the app you wish to close (for example Safari.app). To find the name, open Activity Monitor and use the Process Name, then enter that value into ControlPlane.

Screen Saver Password actions

Unavailable on macOS 15. Actions of type ScreenSaverPassword historically enabled or disabled the screen saver password. Lock Screen settings are no longer controllable this way on Sequoia.

Start Screen Saver Now action

Starts the screen saver

Screen Saver Time actions

Unavailable on modern macOS. Actions of type ScreenSaverTime historically changed the idle time before your screen saver activates via com.apple.screensaver prefs. That path is gated pending a public API; use System Settings → Screen Saver / Lock Screen, or a Run Shortcut instead.

ShellScript actions

Actions of type ShellScript allow you to execute arbitrary shell scripts using /bin/sh. Arguments may be passed to the script by using a pipe character ("|") as a separator in the parameter. (e.g. /path/to/script.sh|argument1|argument2)

Run Shortcut action

Runs a Shortcut from the Shortcuts app by name or identifier. Enter the exact name (or UUID from shortcuts list --show-identifiers). ControlPlane invokes the public /usr/bin/shortcuts run tool with a typed argument list (no shell). The action is only offered when that tool is present (macOS 12+). Use this to set Focus, toggle Bluetooth, or run any other Shortcut when a context becomes active. See Tips and tricks for Focus examples.

Set Focus action

Convenience wrapper around Run Shortcut for Focus modes. Create a Shortcut that uses the system “Set Focus” action for the desired Focus (Do Not Disturb, Sleep, Work, …), then enter that Shortcut’s name. ControlPlane does not write private Notification Center preferences.

Speak action

Speak the entered text

Start Time Machine action

Allows you to start a new Time Machine backup or stop an already running backup

Time Machine Destination action

Unsupported on macOS 15. This action previously required the Tedium companion app to switch Time Machine backup destinations. Tedium is no longer maintained for current macOS; the action remains unavailable until a supported companion or replacement exists.

Toggle Bluetooth action

Unsupported on modern macOS. Actions of type ToggleBluetooth previously used private Bluetooth power APIs and are not available on Tahoe. Existing actions fail with a clear error and no longer call undocumented IOBluetooth Preference symbols. Use Control Center or System Settings → Bluetooth, or a ShellScript action that runs a Bluetooth Shortcut (for example shortcuts run "Toggle Bluetooth").

Toggle WiFi action

Actions of type ToggleWiFi allow you to control the power state of your computer's built-in WiFi controller.

Toggle ControlPlane Context is Sticky

Allows you to toggle if a guesses (or forced) context is sticky. This is useful if you want to stay at a guessed or forced context until you manually select a different one. If you only want a single context to be sticky, remember to set an associated "untoggle" on departure.

Toggle Firewall action

Unsupported on modern macOS (Tahoe / 15/16). Historically toggled the application firewall on or off globally. Existing actions fail with a clear error. Configure the firewall in System Settings → Network → Firewall, or use a Run Shortcut action.

Firewall Rule actions

Actions of type FirewallRule are not available on modern macOS. Per-rule firewall preferences from older OS X releases are no longer supported. Configure firewall settings in System Settings → Network → Firewall.

Toggle Notification Center Alerts

Unsupported on macOS 15. This legacy Do Not Disturb action is not supported on modern macOS (Focus replaced classic Notification Center DND). Existing actions fail with a clear error and no longer write Notification Center preferences. Use a Run Shortcut action that runs a Focus Shortcut instead (see Help tips).

Toggle Printer Sharing action

Unsupported on modern macOS (15/16). Printer Sharing toggles require the privileged helper and are not reliable on current macOS releases. Prefer System Settings → General → Sharing, or a ShellScript action, instead of treating this as a supported ControlPlane action.

Toggle Remote Login action

Allows you to toggle macOS's ssh service (Remote Login). This action uses the privileged helper when first needed.

Toggle Time Machine action

Toggles Time Machine on or off. This action requires additional privileges and when first invoked will ask you to install a helper application. Simply click install to install the helper application.

Unmount action

Unmounts a given disk

VPN actions

Unsupported on modern macOS (15/16). Actions of type VPN are not available on modern macOS. ControlPlane does not connect or disconnect VPN sessions in this release. Use System Settings → VPN, or Shortcuts, instead.

Unavailable on modern macOS (15/16)

The following actions are retired or gated and are not supported on macOS 15/16. They are listed here so older documentation and configs are not mistaken for current guidance:

  • Toggle FTP Sharing — retired
  • Toggle TFTP Sharing — retired
  • Toggle Web Sharing — retired
  • Toggle Internet Sharing — retired
  • AFP file sharing options — retired (SMB-only file sharing may still apply where offered)
  • Toggle Bluetooth — unavailable
  • Toggle Natural Scrolling — unavailable
  • Screen Saver Password — unavailable
  • Screen Saver Time — unavailable
  • Toggle Notification Center Alerts (legacy Do Not Disturb) — unavailable
  • Network Location — unsupported
  • VPN — unsupported
  • Toggle Firewall / Firewall Rule — unsupported
  • Toggle Printer Sharing — unsupported
  • Time Machine Destination (Tedium) — unsupported
  • Display Brightness — unsupported
