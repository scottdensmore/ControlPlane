Diagnostics and logging

The Diagnostics preferences pane shows why ControlPlane prefers one context over another: current context, leading confidence guess, per-rule match state, each rule’s confidence contribution, and a snapshot of enabled evidence sources.

Reproducing a mis-switched context

  1. Create contexts Home and Work.
  2. Add a Power rule on Home (parameter Battery) with high confidence (for example 90%).
  3. Add a Wi‑Fi rule on Work for your office SSID with lower confidence (for example 55%).
  4. Set Confidence required to switch to about 75%.
  5. Force Work from the status menu, then unplug AC power (or otherwise match the Battery rule) while still associated with the office network.
  6. Open Settings → Diagnostics. The explanation should prefer Home over current Work, list the matching Power rule as contributing to the leading guess, and show evidence (Power / Wi‑Fi) in the snapshot.

Unified logging

ControlPlane writes to the system unified log with subsystem com.scottdensmore.ControlPlane and categories Evidence, Rules, Actions, Helper, and General.

Example:

log stream --predicate 'subsystem == "com.scottdensmore.ControlPlane"' --level debug

The Advanced preferences pane still shows an in-app ring buffer of recent log lines for quick inspection without Console.
